Política de privacidad

Última actualización: 16 de octubre de 2026

Esta política explica cómo trata Lêda Felix la información relacionada con Próxima Página Librero y con el sitio web Próxima Página.

Quién presta el servicio y contacto

La responsable del proyecto y punto de contacto es Lêda Felix. Para consultas de privacidad, escribe a proximapaginainfo@gmail.com.

Información tratada por el plugin

Próxima Página Librero no tiene un servidor o base de datos propios para almacenar tus preferencias, consultas o recomendaciones. El plugin puede utilizar los datos que compartas en la conversación —por ejemplo, preferencias de lectura, libros que te gustaron o que no te gustaron— para responderte dentro de ChatGPT. OpenAI trata esa conversación conforme a sus propios términos y políticas de privacidad. La responsable del plugin no recibe una copia ni conserva un historial independiente de esas conversaciones.

Cuando se realiza una búsqueda web desde ChatGPT, OpenAI puede enviar a proveedores de búsqueda consultas generadas o reformuladas para obtener resultados. El tratamiento de esas consultas se rige también por las políticas de los servicios correspondientes.

Mensajes de soporte por correo

Si escribes al correo de soporte, trataremos tu dirección y el contenido del mensaje para responder y atender la consulta. Los conservaremos mientras se atiende la consulta y, después, solo durante el plazo necesario para posibles reclamaciones u obligaciones legales. No se fija un plazo único porque la duración depende de esas necesidades. Puedes solicitar la supresión escribiendo al mismo correo, sin perjuicio de la información que deba conservarse por obligación legal o para gestionar reclamaciones.

Visitas al sitio

La web está alojada mediante GitHub Pages. La responsable no ha incorporado analítica propia, píxeles publicitarios ni almacenamiento de preferencias en el sitio. GitHub puede tratar datos técnicos de las visitas, como direcciones IP, por motivos de seguridad y funcionamiento, de acuerdo con sus propias políticas. Consulta la Declaración de privacidad de GitHub y la información de GitHub Pages.

Destinatarios y derechos

La responsable no vende ni comparte con fines publicitarios los datos recibidos por correo. Los proveedores de la plataforma de conversación, búsqueda y alojamiento pueden tratar datos técnicos o de conversación como parte de sus servicios, bajo sus propias condiciones. Para ejercer derechos de acceso, rectificación, supresión u oposición que correspondan, o para plantear una consulta, escribe a proximapaginainfo@gmail.com. También puedes acudir a la autoridad de protección de datos competente.

Cambios

Esta política puede actualizarse si cambian las prácticas del servicio. La fecha de actualización aparecerá al inicio.
