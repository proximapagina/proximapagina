Términos de uso

Última actualización: 16 de octubre de 2026

Estos términos se aplican al uso de Próxima Página Librero, un asistente de recomendaciones lectoras ofrecido por Lêda Felix a través de ChatGPT. Al utilizarlo, también debes cumplir las condiciones aplicables de ChatGPT y OpenAI.

Qué ofrece

El asistente usa las preferencias que compartes para buscar y sugerir libros y, cuando las fuentes lo permiten, datos de edición como editorial, páginas, idioma e ISBN. Las recomendaciones y los datos bibliográficos son informativos; pueden contener errores, variar entre ediciones o dejar de estar actualizados. Comprueba los datos en fuentes editoriales o catálogos antes de tomar decisiones importantes.

Límites del servicio

El asistente no vende libros, no tramita compras, pagos, suscripciones ni pedidos, y no confirma existencias o disponibilidad local. Una recomendación no garantiza que un libro esté disponible ni que sus datos sean completos. El servicio puede no ofrecer cinco resultados si no encuentra suficientes candidatos que cumplan tus preferencias.

Uso responsable

No compartas información sensible que no sea necesaria para obtener recomendaciones. No uses el servicio para infringir derechos de terceros ni para actividades ilícitas. Podemos modificar o interrumpir el servicio y actualizar estos términos cuando sea necesario.

Contacto

Para consultas sobre estos términos o el servicio, escribe a proximapaginainfo@gmail.com.

Alcance

Estos términos no limitan derechos que te correspondan de forma irrenunciable conforme a la legislación aplicable.
